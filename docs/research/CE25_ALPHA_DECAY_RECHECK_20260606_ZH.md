## 后续研究路线

接下来应该纵向推进，不应该再继续泛泛横向找账号。

### Step 1：把 P0 收窄成一个更硬的策略

从：

```text
ce25_btc5m_first20_35
```

收窄为：

```text
CE25_BTC5M_LAST60_FIRST20_35_V2
asset = BTC
tf = 5m
time_to_close <= 60s
first_leg_price in [0.20, 0.35]
projected_pair_cost <= 0.95 initially
hard projected_pair_cost <= 0.98
residual cap <= 12%-15%
```

### Step 2：对 65-80 只保留 BTC 5m 小仓版本

```text
CE25_BTC5M_FIRST65_80_STOP_1_5M_V2
asset = BTC
tf = 5m
60s < time_to_close <= 300s
first_leg_price in [0.65, 0.80]
projected_pair_cost <= 0.96 preferred
hard projected_pair_cost <= 0.98
small size only
```

### Step 3：进入 ex-ante replay

public profile 只能证明 ce25 账户做到了，不能证明我们能做到。下一步必须验证：

- 当时 L1/L2 是否真有可成交价格；
- 用 sweep VWAP 后 pair_cost 是否仍低；
- completion leg 是否能在 SLA 内完成；
- fee stress 后是否仍正；
- 容量从小额扩大后是否消失。

## 最终定论

ce25 近期确实有策略层面的退化，但退化发生在 **全账户/broad last_60s/65-80 全资产桶**，不是发生在最核心的 **BTC 5m 低价尾段桶**。

因此现在不应放弃 ce25，而应做两件事：

1. 放弃 ce25 全账户和 broad last_60s。
2. 把 `BTC 5m / last_60s / first20_35` 作为 P0，进入严格 ex-ante replay。

如果这个 P0 在 replay 里也失效，才算 ce25 主 alpha 真正不可复现。
